# 👶 Manual Paternidade

Uma proposta de atividade pedagógica para apoiar pais de primeira viagem nos cuidados com o bebê.

 ## Sobre o projeto

O Manual Paternidade é uma aplicação web desenvolvida com o objetivo de reunir orientações básicas para pais de primeira viagem, contribuindo para uma experiência mais informada e segura nos primeiros cuidados com o bebê.

O projeto apresenta dicas práticas sobre situações do dia a dia, como dar banho, segurar o bebê no colo e compreender o choro, por meio de páginas simples e acessíveis.

O conteúdo foi elaborado com base no material ["Manual para Pai de 1ª Viagem (PDF)"](https://www.extranet.ceuma.br/ceuma-wordpress/wp-content/uploads/2019/12/Manual_-para_PAI_de-1%C2%BA_viagem.pdf).

### 🛠️ Tecnologias utilizadas
- HTML5 — estruturação das páginas.
- CSS3 — estilização e apresentação visual.
